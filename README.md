# Survey Feedback Analyzer 📝

## 📌 Project Overview

Survey Feedback Analyzer is a Python Fundamentals project designed to analyze customer feedback using basic Python programming concepts.

This project collects survey feedback, cleans text data, analyzes word frequency, calculates average ratings, identifies the longest feedback, and extracts unique words.

## 🎯 Objectives

* Store feedback data using Dictionary and Lists.
* Collect additional feedback from users.
* Perform text cleaning.
* Count specific words in feedback.
* Calculate average ratings.
* Find the longest feedback.
* Identify unique words.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook

## 📚 Python Concepts Used

* Dictionary
* Lists
* For Loop
* Conditional Statements
* Functions
* String Methods
* Sets
* Built-in Functions

## ⚙️ Project Features

1. **Preloaded Feedbacks:** Stores 10 sample customer feedbacks.
2. **Add More Feedbacks:** Allows users to enter additional feedback.
3. **Text Cleaning:** Removes punctuation, extra spaces, and converts text to lowercase.
4. **Word Count Insights:** Counts feedbacks containing good, poor, and excellent.
5. **Final Summary:** Calculates average rating, finds the longest feedback, and identifies unique words.
6. **Sorting:** Sorts feedbacks based on ratings (highest to lowest).

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open Jupyter Notebook.
3. Open `Survey_Feedback_Analyzer.ipynb`.
4. Run each cell sequentially.
5. Enter additional feedback when prompted.
6. View the final analysis and insights.
